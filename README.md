# HyperFPS — Minecraft 1.20.1 (Fabric)

Trois coupes de rendu, toutes réglables, toutes côté client.

Publié sur Modrinth : https://modrinth.com/mod/hyperfps

- **Les entités** cessent d'être dessinées au-delà d'une distance calculée à partir de ta distance
  d'affichage multipliée par un facteur que tu choisis.
- **Les block entities** — coffres, fours, pancartes — ont leur propre réglage, parce que ce sont
  elles qui coûtent cher dans une base construite.
- **Les particules** sont échantillonnées au lieu d'être toutes créées.

Aucun bloc, aucun objet, rien qui change la façon dont le jeu se joue. Rien à installer côté
serveur.

## Compiler

```
./gradlew build
```
